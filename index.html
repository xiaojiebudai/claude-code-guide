Claude Code 是什么？

Anthropic 官方出品的 AI 编程助手 CLI 工具

终端原生

在终端中直接与 Claude 交互，无需离开命令行环境。支持 Bash、Zsh、PowerShell。

文件操作

读写文件、搜索代码、批量编辑、Git 操作等，所有工具调用均需授权。

技能系统

通过 Skills 扩展专业领域能力，支持全局安装和项目级安装。

插件生态

丰富的 Plugin Marketplace，一键安装社区贡献的插件和技能包。

Hooks 自动化

通过生命钩子（SessionStart、PostToolUse 等）自动触发行为。

跨会话记忆

MEMORY.md + 技能系统实现持久的项目知识积累。

提示：Claude Code 最强大的地方在于它不仅仅是代码补全——它能理解整个项目、执行多步骤任务、并持续学习你的偏好。

基础命令速查

日常使用频率最高的命令

命令功能使用场景
/help 显示帮助信息 查看所有可用命令和功能说明
/clear 清空对话上下文 开始全新任务，释放上下文窗口
/compact 压缩对话历史 上下文接近上限时，自动压缩保留关键信息
/config 打开配置面板 修改主题、模型、权限等设置
/init 初始化项目 CLAUDE.md 为新项目生成 AI 上下文配置文件
/status 查看当前会话状态 了解上下文使用情况、已加载技能
/stats 查看使用统计 了解 Token 消耗和会话数据
/plan 进入计划模式 复杂任务先做方案设计，确认后再执行
/review 代码审查 审查当前分支的改动
/security-review 安全审查 检查待提交代码的安全隐患

技能（Skills）系统

扩展 Claude Code 专业能力的核心机制

技能是什么？

技能是包含专业知识的 Markdown 文件（SKILL.md），通过 YAML 前置元数据定义名称和触发条件。Claude Code 在需要时会自动加载匹配的技能。

安装技能

# 全局安装（所有项目可用） npx skills add vercel-labs/skills --skill find-skills -g -y # 项目级安装 npx skills add anthropics/skills --skill skill-creator -y # 搜索技能 npx skills find "browser" # 列出已安装 npx skills ls -g

推荐技能包

  • find-skills — 搜索/发现新技能
  • skill-creator — 创建自定义技能
  • agent-browser — 浏览器自动化
  • UI/UX Pro Max — 专业 UI 设计指导
  • self-improving-agent — 跨会话学习
  • superpowers — TDD + 调试 + 代码审查
  • claude-mem — 持久化记忆系统

插件（Plugins）系统

比 Skills 更强大的扩展机制，包含 Agents、Hooks、Commands

# 添加插件市场 /plugin marketplace add affaan-m/everything-claude-code # 从官方市场安装 /plugin install superpowers@claude-plugins-official # 列出已安装插件 /plugin list # 更新插件 /plugin update ecc@ecc
Superpowers

20+ 技能：brainstorming、TDD、debugging、code-review、git-worktrees 等。遵循"先设计再执行"的工程纪律。

ECC

Everything Claude Code：47 Agents + 232 Skills + 79 Commands，完整的开发工作流套件。

claude-mem

跨会话持久记忆：SQLite + 向量嵌入 + 自动压缩，让 Claude 记住所有项目上下文。

Hooks 自动触发器

在特定事件发生时自动执行脚本或命令

可用钩子类型

钩子触发时机典型用途
SessionStart会话开始时加载项目上下文、初始化环境
UserPromptSubmit用户提交消息后注入提醒、检查规则
PreToolUse工具调用前权限检查、参数校验
PostToolUse工具调用后错误检测、日志记录
Stop会话结束时保存状态、清理资源

配置示例 (~/.claude/settings.json)

{ "hooks": { "UserPromptSubmit": [{ "matcher": "", "hooks": [{ "type": "command", "command": "bash ~/.claude/skills/self-improving-agent/scripts/activator.sh" }] }] } }

记忆系统

让 Claude 在多次对话中持续积累项目知识

CLAUDE.md

项目根目录的 AI 上下文文件。记录项目架构、技术栈、编码规范、常见陷阱。每次会话自动加载。

MEMORY.md

用户级持久记忆索引。存储跨项目的偏好、反馈、角色信息。位于 ~/.claude/projects/。

.learnings/

Self-improving Agent 的错误日志和学习记录。包含 LEARNINGS.md、ERRORS.md、FEATURE_REQUESTS.md。

claude-mem

全自动插件级记忆：SQLite 数据库 + Chroma 向量搜索 + 观察压缩，无需手动维护。

最佳实践：在 CLAUDE.md 中记录"非显而易见"的信息——项目特有的约定、已知陷阱、构建系统的特殊配置。这些是 AI 无法从代码中推断的。

使用技巧（一）—— 对话效率

如何让 Claude Code 更高效地理解你的意图

具体胜过模糊

"把 src/utils/auth.ts 中的 login 函数改成 async/await 风格" 比 "改进认证模块" 效果好 10 倍。

提供上下文

告诉 Claude 你的技术栈、项目阶段、约束条件。使用 /init 初始化 CLAUDE.md 是好的起点。

善用 @ 引用

在对话中使用 @file.ts 引用文件，@folder/ 引用目录，让 Claude 精确理解上下文。

分阶段执行

复杂任务先用 /plan 做方案，确认后再实施。避免一次请求做太多事情。

黄金法则：想象你在给一个新入职的同事分配任务——提供足够的背景信息、明确期望的输出格式、说清楚哪些不要做。

使用技巧（二）—— 项目配置

通过 CLAUDE.md 和 settings.json 定制 Claude 的行为

CLAUDE.md 结构建议

# 项目名称 ## 技术栈 - 前端：React 18 + TypeScript + Tailwind CSS - 后端：Node.js + Express + PostgreSQL ## 编码规范 - 使用函数组件，避免 class 组件 - API 路由放在 src/routes/ 目录下 - 数据库迁移使用 knex ## 注意事项 - 不要直接修改 dist/ 目录（构建产物） - 测试必须覆盖所有 API 端点
提示：CLAUDE.md 文件越小越好——只记录代码中无法直接推断的信息。超过 200 行建议拆分到多个文件中。

使用技巧（三）—— 高级玩法

进阶技巧，释放 Claude Code 的全部潜力

子代理并行

Claude Code 可以自动派生子代理并行处理独立任务。在 Superpowers 的 subagent-driven-development 技能中开箱即用。

Worktree 隔离

使用 EnterWorktree 在隔离的 Git 工作树中进行实验性修改，不影响主工作区。Superpowers 会强制使用此模式。

循环任务

使用 /loop 命令设置定时执行的提示词。适合轮询 CI 状态、定期检查部署等场景。

TDD 工作流

Superpowers 的 TDD 技能强制执行 RED→GREEN→REFACTOR 循环，确保每个改动都有测试覆盖。

MCP 扩展

通过 Model Context Protocol 连接外部工具和 API。ECC 内置了 6 个 MCP 服务器配置。

一键 PR

在 Claude Code 中直接使用 gh pr create 创建 PR，Claude 会自动生成标题和描述。

使用技巧（四）—— Vibe Coding 效率

少打字，多说话——语音输入 + AI 编程的黄金组合

Win + H 语音输入

Windows 11 自带，无需安装任何软件。按 Win + H 即可启动，支持中英混合识别。

最适合的场景

描述需求、解释思路、写注释、commit message、PR 描述。这些都是自然语言场景，语音比打字快 3-5 倍。

与 Claude Code 协作

用 Win+H 说清楚目标 → Claude Code 写代码 → 你审查结果。你只需"说清楚要什么"，代码交给 AI。

微信语音转文字

PC 端微信的语音转文字功能准确率也很高，适合写长文档、PRD、设计说明等内容。

实操流程

1. 按 Win+H 打开语音输入 2. 口述需求： "帮我创建一个用户登录页面，包含邮箱和密码输入框， 使用 Tailwind CSS 样式，登录成功后跳转到 /dashboard" 3. Claude Code 生成代码 4. 用语音说修改意见： "把按钮颜色改成蓝色，加上加载状态， 密码输入框右边加一个显示/隐藏的切换按钮" 5. 再次审查，完成
核心原则：Vibe Coding = 语音说需求 + AI 写代码 + 人工审查。代码符号（{}、=> 等）交给 AI，你只负责用自然语言描述"想要什么效果"。Win+H 零成本、零配置，开箱即用。

配置管理

理解 settings.json 的层级和关键配置项

配置层级（优先级从高到低）

  • 项目级 — .claude/settings.json
  • 项目级本地 — .claude/settings.local.json
  • 用户级 — ~/.claude/settings.json

关键配置项

  • env — 环境变量（模型、API Key 等）
  • hooks — 钩子配置
  • enabledPlugins — 启用的插件
  • extraKnownMarketplaces — 自定义市场
  • verbose — 详细输出模式
  • includeCoAuthoredBy — Git Co-Author

权限管理

通过权限系统控制 Claude 可以执行的操作类型：

  • Allow — 始终允许的操作
  • Ask — 每次询问确认
  • Deny — 完全禁止
# 允许所有 npm 命令 /permit npm # 查看当前权限 /status
