为什么要用 Claude Code + DeepSeek？

最佳性价比组合

Claude Code

Anthropic 官方出品的 AI 编程助手 CLI。完整的工具链：文件读写、Git 操作、插件系统、Hooks 自动化。

DeepSeek

中国 AI 公司深度求索。API 价格极低（约为 Claude 的 1/50），通过 Anthropic 兼容协议无缝接入。

价格优势

DeepSeek-V4-Pro 输入 ¥1/M tokens，输出 ¥4/M tokens。Claude Code 平均一天消耗约 ¥2-5。

免翻墙

DeepSeek API 国内直连，无需代理。充值支持微信、支付宝。充值 ¥50 够用一个月。

一句话总结：用 Claude Code 的工具链（最强大的 AI 编程界面）+ DeepSeek 的模型（最实惠的中文大模型）= 最佳性价比。

准备工作

安装前需要的软件和环境

1

安装 Node.js（必需）

Claude Code 基于 Node.js 运行，需要 v18+ 版本。

# 方式一：官网下载（推荐） 打开 https://nodejs.org → 下载 LTS 版本 → 安装 # 方式二：nvm（版本管理，推荐开发者） nvm install 22 nvm use 22
2

安装 Git（推荐）

Claude Code 深度集成 Git 工作流，建议安装。

# 下载安装 https://git-scm.com/downloads
3

注册 DeepSeek 并获取 API Key

访问 DeepSeek 开发者平台，创建 API Key。

# 注册地址 https://platform.deepseek.com # 步骤 注册 → 充值（¥10 起，微信/支付宝）→ API Keys → 创建 Key → 复制保存

安装 Claude Code

一行命令即可安装

全局安装

# npm 全局安装 npm install -g @anthropic-ai/claude-code # 验证安装 claude --version # 输出: x.x.x

Windows 用户特别注意

Git Bash 是必须的：Claude Code 需要 Unix shell 环境。Windows 用户请使用 Git Bash 运行，不要在 CMD 或 PowerShell 中运行。

安装 Git 后，右键桌面空白处 → "Git Bash Here" → 在 Git Bash 中执行所有命令。
macOS / Linux：直接在终端中运行即可，无需额外配置。

配置 DeepSeek 接入

核心步骤：修改环境变量指向 DeepSeek API

方法一：全局配置文件（推荐）

创建 ~/.claude/settings.json：

{ "env": { "ANTHROPIC_BASE_URL": "https://api.deepseek.com/anthropic", "ANTHROPIC_AUTH_TOKEN": "sk-你的DeepSeek-API-Key", "ANTHROPIC_MODEL": "deepseek-v4-pro", "ANTHROPIC_DEFAULT_HAIKU_MODEL": "deepseek-v4-pro", "ANTHROPIC_DEFAULT_SONNET_MODEL": "deepseek-v4-pro", "ANTHROPIC_DEFAULT_OPUS_MODEL": "deepseek-v4-pro" } }

方法二：环境变量（临时）

# 在终端中执行（每次新终端都要执行） export ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic" export ANTHROPIC_AUTH_TOKEN="sk-你的Key" export ANTHROPIC_MODEL="deepseek-v4-pro" # 可写入 ~/.bashrc 或 ~/.zshrc 持久化

更新模型配置

修改 ~/.claude/settings.json 中的 ANTHROPIC_MODEL 即可切换模型。

# 切换到 deepseek-chat（更省钱） "ANTHROPIC_MODEL": "deepseek-chat"
建议：日常使用 deepseek-v4-pro，它在代码理解和生成方面表现最好。简单脚本类任务用 deepseek-chat 即可。

常见问题

中国用户最常遇到的问题

Q: 提示 "command not found: claude"

Node.js 全局安装路径未加入 PATH。重启终端，或手动添加 %APPDATA%\npm 到系统 PATH。

Q: 连接 DeepSeek API 报错

  • 检查 ANTHROPIC_BASE_URL 是否正确：https://api.deepseek.com/anthropic
  • 检查 API Key 前缀是否为 sk-
  • 检查 DeepSeek 账户是否有余额

Q: Windows 下中文乱码

在 Git Bash 选项中设置字符集为 UTF-8，或使用 Windows Terminal。

Q: 如何更新 Claude Code？

claude update # 或 npm update -g @anthropic-ai/claude-code

Q: DeepSeek 和 Claude 原版有什么区别？

DeepSeek 通过 Anthropic 兼容协议接入，实现了相同的消息格式和工具调用协议。功能上与 Claude 原版完全一致，价格便宜 50 倍。可能在某些极端边缘场景下略有差异，但日常开发完全够用。

使用建议

经过验证的最佳实践

创建 CLAUDE.md

在项目中运行 /init，让 Claude 了解项目结构、技术栈和编码规范。

搭配 Win+H 语音输入

Windows 自带的 Win+H 语音输入 + Claude Code，实现 Vibe Coding：说需求 → AI 写代码。

保持更新

Claude Code 更新频繁，建议每周运行 claude update。新版本常带来重大改进。

使用 Git 工作流

重要改动先创建分支，让 Claude 在隔离环境中工作，审查通过后再合并。

最终建议：Claude Code 不是代码补全工具，它是一个自主编程代理。不要让它只写一行代码——给它完整的任务描述，让它规划、执行、审查、提交。
